# zoedewitte.com

**Dino Rêveur** : un petit jeu de course proposé par Zoé Dewitte.

- Sautez (Espace / ↑ / toucher), baissez-vous (↓ / glisser vers le bas), pause (P).
- Étoiles à ramasser, bulle protectrice, ptérodactyles, cycle jour/nuit.
- Défi du jour, tableau d'honneur local, badges, dinos à débloquer, statistiques.

Site 100 % statique (HTML/CSS/JS, sans dépendance ni build) hébergé sur GitHub Pages.
Toutes les données restent dans le `localStorage` du navigateur du joueur.
